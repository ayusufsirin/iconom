# Task Template

## Objective

State the specific result to produce in one or two sentences.

## Allowed Files

List the exact files or directories the worker may edit.

## Forbidden Files

List any files or paths that must not be touched.

## Acceptance Checks

List the concrete checks that define done. Prefer deterministic smoke checks over vague expectations.

## Out of Scope

List architecture changes, cleanup work, or follow-on tasks that are not part of this brief.
